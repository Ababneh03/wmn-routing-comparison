## Recompile in Overleaf

1. Download `Overleaf-source.zip`.
2. In your own Overleaf account, choose **New Project → Upload Project** and select the ZIP.
3. Select `main.tex` as the main document and pdfLaTeX as compiler.
4. Compile until bibliography and cross-references settle.

The original Overleaf project is not modified by this public copy. No simulator installation is required to read or compile the thesis.
