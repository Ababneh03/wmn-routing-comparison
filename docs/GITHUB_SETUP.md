# Publish this project with GitHub Desktop

Suggested repository name: **wmn-routing-comparison**.

Suggested description:

> OMNeT++/INET mesh-routing experiment with AODV/DSDV configurations, reproducible baseline runs, Python analysis, and a documented model audit.

Suggested topics: `omnetpp`, `inet`, `wireless-mesh-networks`, `aodv`, `dsdv`, `network-simulation`, `python`.

## Add the local repository

1. In GitHub Desktop, choose **File → Add Local Repository**.
2. Select the `wmn-routing-comparison` folder prepared with this draft.
3. Review the included files. Raw simulation recordings, local paths, and environment files are excluded by `.gitignore`.
4. Review the project license status in `NOTICE.md` before choosing any open-source license.
5. Commit the reviewed project, then use **Publish repository**. Choose the intended visibility there.
6. Open the published repository in your browser, add the description/topics, and pin it to your profile.

Keep publication metadata and citations accurate. The published paper and the repository's later baseline execution check are different research artifacts.

## Useful profile presentation

Feature the project with a short explanation of its research question, the tools it uses, and the work you personally contributed. Describe the current model audit as ongoing technical improvement. Avoid claiming a new routing algorithm or a verified performance improvement that this baseline does not establish.
